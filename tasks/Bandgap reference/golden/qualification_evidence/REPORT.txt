VALIDATION AND QUALIFICATIONS

Bandgap: canonical and tighter-tolerance full verification each pass 90/90 checks. An independent temperature sweep at 0.25 C intervals passes 15/15, with maximum TC 17.12259677 ppm/C. All 50 canonical decks regenerate byte-for-byte, preserving 22 named MOS instances and the original connectivity.

The bandgap changes from the prior 13/15 candidate are the PTAT-reference M4 width, independent M11/M13 widths and resistor ratios. The transistor models and corner files were not changed. M13 W = 1.67 um is within one PDK width bin. Sensitivity predictions that crossed the 1.68 um bin boundary did not reproduce accurately; final sizes were accepted only after actual simulation. The retained candidate uses no extra gain-stage multiplicities.

DTMOS: canonical full 60 ms transient, AC and DC checks pass 48/48. Independent AC/DC checks with 1000 points/decade and tighter tolerances pass 36/36. Maximum numerical movement was 0.000336421 dB for gain and 0.01571956 Hz for cutoff. All 12 decks regenerate exactly.

DTMOS gain acceptance is at 200 Hz. Applying the same target band to passband gain fails; its observed range is -0.684635 to +0.892298 dB. This result does not resolve the paper graph's unspecified measurement frequency.

DTMOS total MOS gate area is 9547.358 um2 (0.00954736 mm2), or 9.78969 times the prior 11/12 candidate. Mpb1 and Mpb2 each use W/L = 100/0.18 um with native m = 242. Multiplicity, current and capacitance scaling were verified experimentally. The original 17 named devices and four gate-body ties remain; multiplicity represents actual parallel units.

DTMOS C1 = 70.673153 nF and C2 = 908.083911 nF. C2 is three times its prior value. Capacitors remain ideal lumped elements. Gate-area estimates exclude capacitor area, diffusion, isolation and routing; they are not layout-area estimates.

At 100 C, DTMOS M2 operates in weak inversion: Id = 0.108407 uA and VGS - VTH = -0.128122 V. This does not fail an enforced metric. An additional requirement for strong inversion everywhere would fail. Layout/parasitics and mismatch/Monte Carlo have not been validated.

The independent review found no blocking defect under these stated scopes. See INDEPENDENT_REVIEW.txt. Directional summaries use the true adverse extrema or nearest bound. Legacy aggregate 'worst' labels are retained only in the canonical audit files.
