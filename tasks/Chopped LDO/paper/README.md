# Infineon chopped LDO, 1.5 V output (cell_ldo)

A 2.5 V-to-1.5 V LDO in a PTM-based 130 nm technology, built as a defect-simulation benchmark: a chopped two-stage Miller op-amp wired as an integrator (20 pF feedback capacitor) compares the 1.2 V reference with the 300k/1.2M divided output, and its output passes through a two-capacitor (2 x 500 fF) switched-capacitor filter to remove chopper ripple. The output stage is a flipped-voltage-follower structure: an NMOS source follower (M1, 24 x 10/0.4 um) whose drain current flows through a long-channel PMOS resistor and drives the gate of the large PMOS pass device M0 (150 x 40/0.4 um), giving a fast local loop with no external output capacitor (the testbench uses 1 pF). Two hysteretic comparators on a supply divider flag under-/over-voltage (2.3 V / 2.8 V) and disable the regulator; on-chip logic divides the 400 kHz clock into the 90-degree-shifted chopper and SC-filter phases.

- **Topology / sub-topology:** LDOs / Capacitorless flipped-voltage-follower LDO
- **Repository:** https://github.com/Infineon/adsbenchmark (commit `d1f5c9be021970e8c1fda5a2c5eea3987cb9667c`)
- **Top cell:** `cell_ldo` in `LDO/src/tb_ldo.hsp`
- **Device count:** 430 (342 MOSFET, 76 BJT substrate diodes, 7 R, 5 C)

## Files

- `metrics.xlsx`: sheet **Metrics** (performance numbers with sources) and sheet **Sizing** (every device with W/L/nf/m or value, file, line and permalink).

- `schematics/`: schematic images, the complete netlist (`netlist/`, unmodified copy of the repo `src/` folder) and the documentation PDF, listed below.

Every device of these blocks, with W/L/m and line number, is in the Sizing sheet.
- Printed page numbers in this PDF equal the physical page index (front matter is pages I-IV = physical 1-4), so "page N" is both.
- Metrics are documentation values (LDO.pdf Tables 1-2 and text), plot cursor annotations (Figures 7-8) and the Verilog-A checker's pass/fail limits; the repo contains no simulation result files, so there are no measured or logged results and corner_results is empty.
- The checker README (LDO/doc/readme) says the checker limits are defaults that users may shift based on defect-free simulation results.
- Schematics come only from the PDF (the repo has HSPICE netlists, no schematic files). The clock-generation sub-cells (cell_freq_divider, cell_edge_equalizer) and the standard logic gates (dig_hv_lib INV/NAND/AND/OR/BUF/DEL) have no figures; they are digital and appear only as symbols in Figures 2 and 5.
- The doc text (page 8) says the transistor M2 in Figure 4 acts as the resistor; in the netlist (tb_ldo.hsp line 227) this device is named M9 (PANA, W = 400n, L = 20u, gate tied to VSS). Device names in the PDF figures may differ from the netlist.
- Thresholds stated in Table 1 (2.3 V / 2.8 V) and the Figure 8 cursor readings (2.30257 V / 2.79772 V) are rising-supply values; the comparator hysteresis (about 47.5 mV at the comparator input) shifts the falling-supply trip points.
