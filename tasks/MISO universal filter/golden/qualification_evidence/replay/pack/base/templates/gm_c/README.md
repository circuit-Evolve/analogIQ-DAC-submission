# gm-C frozen paper-start sizing adapter

The source is `<WORK>/four-papers-20261107/gm_c`, read only. All templates and provenance files in this directory were copied from that project. `provenance.json` contains their SHA-256 hashes. The task inlines the frozen core into each complete deck; it never imports source scripts or references the original core at runtime.

The paper seed uses the exact simulator dimensions from Table 1 and the exact saved inferred capacitor value, 7.65804778642 pF. The one-time derivation records 7.658047786423189 pF before deck formatting. These are the same initial assumption at the recorded precision. Capacitances are never recomputed from a candidate's gm. Each of the four physical OTA cores contains the same 32 MOS instances, including repeated red devices. The interpreted right inverter pins, inferred passive side-summing adapters, and Fig3 routing remain frozen. The literal OTA variant remains a diagnostic and mirrors candidate geometry. This is the existing executable hypothesis, not a recovered or proven fourth-order paper-exact circuit.

The 31 variables comprise 14 device groups, each with independent W and L, two symmetric capacitor pairs, and the existing VT tuning bias. Shared core geometry preserves consistency between standalone OTA objectives and the full filter. Width bounds are max(120 nm, seed/5) through 10*seed; length bounds are 100 nm through 1 um. Each capacitor pair spans 0.1 pF through 10 nF. VT spans 0.1 through 0.9 V, initially 0.5 V. Bounds are engineering search limits rather than claims from the paper. M=1, input waveforms, supply, VREF, common mode, temperature, model section, and all four equal 1 kohm inferred side-summing resistors remain fixed. Width changes propagate source/drain diffusion areas and perimeters through the copied engine helper.

`search_full` runs OTA_DIFF, OTA_CM, and FILTER_AC_NOISE, preserving each saved sweep and extraction. The six scored quantities are differential gain at 1 Hz, first falling unity-gain crossing, differential unity-feedback phase-margin proxy, common-mode gain at 1 Hz, first falling filter -3 dB crossing relative to DC, and differential output noise divided by differential gain at assumed 1 MHz. All six targets retain arithmetic +/-10% bands, with negative common-mode-gain endpoints sorted. Missing crossings, missing files/signals, nonfinite waveforms, zero normalization, or invalid frequency coverage never create substitute scalar values. Errors and missing scalars remain visible for the shared judge to fail.

`full` (aliases `full_verify`, `verification`, `final`) additionally runs the saved literal OTA, 14 fixed amplitude compression jobs, existing two-tone IP3 job, and existing filter transient. It reports P1dB and IIP3 only in diagnostics with `diagnostic_only=true` and `NOT_COMPARABLE_MISSING_PAPER_CONDITIONS`; neither contributes to optimization acceptance. Their original assumed conditions, Fourier window, power reference, and contradictory paper IP3 labels remain disclosed in `assumptions.json`. Peaking is also disclosed in filter diagnostics. No THD, power, area, additional corner, or postlayout target is invented.

Checks: `python3 pack/gm_c_test.py` verifies seed identity, all mutation bindings, diffusion geometry, unchanged topology/stimuli, rejected malformed designs, missing-output behavior, missing/nonfinite crossing behavior, and exact saved scalar definitions. `python3 pack/gm_c_preflight.py` performs fresh full paper-seed verification plus a physical 10% input-PMOS width mutation, with at most two concurrent Spectre jobs; results are in `preflight/gm_c/proof.json`. That script does not launch LEDRO or touch any earlier search. Search outputs preserve all original save directives (about 94 MB/design before shared-engine trial cleanup); full diagnostics use more raw storage.
